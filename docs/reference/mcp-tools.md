# MCP tools

Generated by `pnpm generate:reference` from the operation registry (OpenOutbound 0.1.0). Do not edit by hand; edit the tool and operation definitions instead.

Select toolsets with `openoutbound mcp --toolsets core,leads` (or `OPENOUTBOUND_MCP_TOOLSETS`, or `/mcp?toolsets=` over HTTP). `all` selects every toolset. Composite tools take an `action` plus the fields of that action. Every call also accepts `workspace`, `reason` and `idempotency_key` (not repeated below); read actions accept `response_format` and spend or send actions accept `dry_run`.

### `create_campaign`: Create or edit campaigns

Build campaigns: create (from a built-in template like signal_based_email_4 or from steps, with offer, senders, schedule, review level and writing instructions), update (settings are deep-merged; keep step ids when editing live campaigns), pick_winner (end an A/B test: keep one variant of an email step), duplicate, delete (drafts only, others are archived) and save_as_template. New campaigns are drafts and send nothing until launched with launch_campaign. Preview drafts first with preview_campaign.

Actions:
- create: Create a campaign from a template or from steps.
- update: Change a campaign's settings, offer or steps.
- pick_winner: End an A/B test by keeping the winning variant.
- duplicate: Copy a campaign (settings and steps) as a new draft.
- delete: Delete a draft campaign, or archive one that has history.
- save_as_template: Save a campaign's steps and settings as a reusable template.

Use pause for temporary holds; stop and archive cannot be undone. To stop all sending in the workspace, pause the workspace instead.

- stop: Stop a campaign for good (every running enrollment ends).
- archive: Archive a campaign (stops it and hides it from active lists).
